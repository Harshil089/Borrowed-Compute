Borrowed Compute

Versionlatest
Needs
Windows 10 or 11, 64-bit
File
BorrowedCompute-setup.exe
  1. Run the installer. If SmartScreen warns, choose More info, then Run anyway.
  2. Paste your Mac's code, click Test, then sign in with the same account as on the Mac.
  3. Click Pair, type the code it shows on the Mac, and run your first command.
