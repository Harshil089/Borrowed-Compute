Not a remote screen.
Not a server to babysit.

        
Remote desktop streams pixels. A build box needs keys, an address and upkeep. Borrowed Compute sends your source and one command, runs it on the other computer's own toolchain, and sends the output back.

Output as it happens. Fixes before you ask.

        
Every line streams back the moment the other computer prints it, with timings for connect, upload, first output and total, and whether the path was direct or relayed.

        
    
          
  • Knows Node, Python, Rust, Go and plain HTML, and suggests commands written for the computer that runs them. A bc.toml always wins.
    • 
          
  • node_modules, .venv and build output never upload. It installs and builds first when a command needs them.
    • 
          
  • After a failure from a missing module, command or build file, it fixes the cause and runs once more.
    •

Dev servers stay up. Ports come home.

        
Tick Keep running, or run a dev, start or serve script, and the server stays up on the lending computer until you press Stop, even after yours disconnects. Its ports open at the same address on the computer in front of you.

        
    
          
  • Only ports the server itself listens on are forwarded. Nothing else on the lending computer is reachable.
    • 
          
  • The lending computer stays awake while a server runs, and ports reconnect quietly on flaky networks.

Sealed off from the rest of the computer.

        
A job is your code plus every package it installs, so the lending computer treats it as untrusted. Each runs in a sandbox, the macOS sandbox on a Mac and an AppContainer on a PC, in a fresh workspace deleted when it ends.

      

      

        
    
          
  • Its own workspaceRead and write
    • 
          
  • Your toolchainsHomebrew · rustup · nvm · pyenv · Xcode · ScoopRead
    • 
          
  • Downloads and its own serversAllowed
    • 
          
  • The rest of your home folder~/Documents · ~/.ssh · ~/.awsBlocked
    • 
          
  • Clipboard, keychain, other apps' settingsBlocked
    • 
          
  • Your ssh agent and local databasesPostgreSQL · Redis · Docker · OllamaBlocked
    • 
          
  • Opening apps on that computerBlocked
    • 
        

        

          
The lending computer stays yours.

          
    
            
  • Only your own account's devices can ask to pair, and only after you approve a code shown on both screens.
    • 
            
  • Devices talk over encrypted QUIC with their own keys. Relays forward traffic they cannot read.
    • 
            
  • Every run, approval and paired device is listed on the lending computer. Remove a device and its new jobs stop within 15 seconds.
    • 
            
  • Updates install only when signed with the project's key.
    •
