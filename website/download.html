For your Mac

Borrowed Compute Agent

Versionlatest
Needs
A Mac with Apple Silicon
File
BorrowedComputeAgent.dmg
  1. Open the disk image and drag the app to Applications.
  2. The first time, macOS blocks it because it is not notarized yet: open System Settings, Privacy & Security, and click Open Anyway.
  3. Sign in, then copy this Mac's code under Route.

For your PC

Borrowed Compute

Versionlatest
Needs
Windows 10 or 11, 64-bit
File
BorrowedCompute-setup.exe
  1. Run the installer. If SmartScreen warns, choose More info, then Run anyway.
  2. Paste your Mac's code, click Test, then sign in with the same account as on the Mac.
  3. Click Pair, type the code it shows on the Mac, and run your first command.
