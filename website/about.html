About

The computer on the shelf is a build machine you already paid for.

Plenty of developers work on one computer and own another that sits idle while they do. Borrowed Compute puts that one to work on the code in front of you, without remote desktop, SSH or a server to look after.

What it holds to

Five rules decide every screen in the app.

  1. 1Speed is the product.

    Progress shows as it happens and real numbers show when it ends. The other computer should feel like it is on your desk.

  2. 2Truthful numbers.

    Times, usage and connection type come from measurement. Nothing is estimated or decorated.

  3. 3One obvious next step.

    Sign in, pair, run. Every state of every screen has a single clear action.

  4. 4The lender stays the owner's.

    Approvals, removals and everything that ran are visible on the lending computer and can be undone there.

  5. 5Developer-native.

    Commands, output and paths are the content, set the way developers read them.
